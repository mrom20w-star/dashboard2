# لوحة تحكم الأدمن المستقلة (React) — Nexus Agency

هذا المجلد يحتوي على **لوحة تحكم الأدمن كاملة** جاهزة للرفع والتشغيل مباشرة على Vercel أو أي استضافة (cPanel / Apache / Hostinger).

---

## طريقتين للرفع والتشغيل فوراً

### 1) الرفع المباشر (مجلد `dashboard/`)
يحتوي المجلد على:
- `index.html` + ملفات `assets/`
- `vercel.json` (لتشغيل الروابط على Vercel بدون خطأ 404)
- `.htaccess` (لتشغيل الروابط على استضافات cPanel / Apache)
- `admin-api.php` (لحفظ البيانات في `data/hpay-db.json` عند وجود PHP)

**الخطوات لـ GitHub + Vercel:**
1. ارفع ملفات مجلد `dashboard/` في جذر مستودع الداش بورد على GitHub (أو حدد `Root Directory = dashboard` من إعدادات Vercel).
2. بعد فتح رابط الداش بورد، ستجد خانة **"ربط الداش بورد بالموقع الرئيسي"** في شاشة الدخول وفي الإعدادات — ضع رابط الموقع الرئيسي (مثال: `https://nexus-agency.vercel.app`) واضغط **ربط**.
3. يمكنك أيضاً فتح اللوحة مباشرة مع الرابط عبر `?api=https://nexus-agency.vercel.app`.

**لحفظ الحسابات والأرصدة بشكل دائم 100% على Vercel:**
- في مشروع الموقع الرئيسي على Vercel: افتح **Storage ← Create Database ← Upstash Redis** (الخطة المجانية)، وسيتم ربط المتغيرات تلقائياً وحفظ كل اللاعبين والأرصدة والإيداعات بشكل دائم عبر كل الأجهزة والموبايلات.

**الخطوات لـ cPanel / Apache / Hostinger:**
- ارفع جميع الملفات الموجودة داخل مجلد `dashboard/` إلى مجلد الاستضافة وافتح الرابط في المتصفح مباشرة.

---

### 2) البناء من الكود المصدري (Local / Git)
```bash
npm install
npm run build
```
الناتج سيخرج في مجلد `dist/`.
